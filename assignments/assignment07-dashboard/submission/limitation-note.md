# Limitation

This dashboard shows unweighted, descriptive mean BMI for adults aged 20-80 in a classroom NHANES dataset, so it does not represent all U.S. adults and cannot show that income causes changes in BMI. NHANES surveys different people in each cycle, so the line compares groups over time, not changes within the same people. Income group is based on self-reported family income, so some people may be placed in the wrong group.

**Where it appears:** the Limitation section of `dashboard.qmd` (same text) and, in shorter form, the figure caption.
